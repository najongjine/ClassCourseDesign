과정명

IoT 센서 데이터 기반 스마트팩토리 설비 고장 예측 AI 서비스 개발자 양성과정

주제

공장 설비에서 발생하는 온도, 진동, 전류, 가동시간 데이터를 활용하여 설비의 이상 징후를 조기에 탐지하고, 고장 가능성을 예측하는 스마트팩토리 AI 예측 서비스를 개발한다.

목적

제조 현장에서 설비 고장은 생산 중단, 납기 지연, 유지보수 비용 증가로 이어진다. 본 과정은 IoT 센서 데이터를 기반으로 설비 상태를 실시간으로 수집·저장·분석하고, 머신러닝 기반 예측 모델을 활용하여 고장 가능성을 사전에 파악할 수 있는 실무형 서비스를 구현하는 것을 목적으로 한다.

목표

수강생은 가상의 공장 설비 센서 데이터를 활용하여 설비 상태 데이터를 수집하고, 서버와 데이터베이스에 저장한 뒤, Python 기반 이상탐지 및 고장 예측 모델을 구현한다. 이후 FastAPI 또는 Node.js API 서버와 React 대시보드를 연동하여 설비 상태, 위험도, 고장 예측 결과를 시각화하는 웹서비스를 완성한다.

PostgreSQL/MySQL 기반 설비 상태 데이터 저장
