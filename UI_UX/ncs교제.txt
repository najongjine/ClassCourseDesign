추가 이론 문구:

UX/UI란
UX와 UI는 공통적으로 사용자 중심의 디자인을 중요시하는 분야이지만, 개념과 역할이 조금씩 다릅니다.

UX(User experience) 정의와 특징
UX는 사용자가 제품, 서비스, 시스템 등을 사용하면서 느끼는 전반적인 경험을 뜻합니다. 여기에는 사용자가 제품을 사용하는 과정에서 느끼는 감정, 태도, 행동 등도 포함되는데요. 즉, UX 디자인을 한다는 것은 사용자가 제품을 사용하면서 어떤 문제를 겪는지 파악하고, 사용자 경험을 향상시키기 위한 솔루션을 제시하는 것을 의미합니다.

UI(User interface) 정의와 특징
UI는 사용자가 제품을 사용할 때 직접적으로 상호작용하는 화면, 버튼, 아이콘 등의 인터페이스 요소를 디자인하는 것을 뜻합니다. UI 디자인은 제품의 시각적 요소를 디자인하며, 사용자가 제품을 사용할 때 필요한 기능을 적절하게 배치하여 사용자 경험을 향상시키는 역할을 합니다.

UX/UI 디자인의 차이점
UX 디자인과 UI 디자인의 차이점을 좀 더 명확히 이해하기 위해 각각의 디자이너들이 어떤 일을 하는지 살펴보겠습니다.

UX 디자이너가 하는일
UX 디자이너는 제품 또는 서비스의 사용자 경험을 개선하기 위한 다양한 작업을 수행합니다. 사용자 조사, 정보 구조 설계, 와이어 프레임 및 프로토타입 제작 등의 작업을 담당하죠. UX 디자이너는 사용자의 니즈와 목표를 이해하고, 해당 제품 또는 서비스가 사용자에게 제공하는 가치를 극대화하기 위해 최적의 경험을 설계합니다.

예를 들어, 음악 스트리밍 앱을 디자인한다고 가정했을 때, UX 디자이너는 음악 검색, 재생 목록, 추천 기능 등에 대한 사용자의 요구를 파악하여 사용자 경험을 향상시킬 수 있는 기능과 디자인을 고민할 것입니다.

UI 디자이너가 하는일
UI 디자이너는 UX 디자이너가 설계한 경험을 시각적으로 구현하는 역할을 맡습니다. 색상, 레이아웃, 아이콘, 버튼 등 디자인 요소를 사용하여 사용자 인터페이스를 디자인하죠. UI 디자이너는 일관된 디자인 언어와 스타일 가이드를 사용하여 사용자가 제품을 직관적으로 이해하고 사용할 수 있도록 돕습니다.

마찬가지로 음악 스트리밍 앱을 예시로 들었을 때, UI 디자이너는 화면의 레이아웃, 버튼 디자인, 아이콘 등을 고려하여 사용자가 앱을 쉽게 탐색하고 사용할 수 있도록 고안할 것입니다.

UX와 UI의 관계
UX 디자인은 사용자가 제품 또는 서비스를 사용함에 있어서 어떻게 느끼고 상호작용하는지를 고려하여 전반적인 사용자 경험을 개선하는 것이 목표입니다. 반면에 UI 디자인은 사용자와 상호작용하는 인터페이스의 시각적인 측면을 다루며, 직관적이고 매력적인 디지털 환경을 제공하기 위해 디자인 요소를 활용합니다. 두 분야는 상호 보완적이며, 협업을 통해 최적의 사용자 경험을 제공할 수 있도록 합니다.

결국 좋은 사용자 경험을 제공하기 위해선 UX와 UI가 유기적으로 연계되어야 한다는 것인데요. 이 때문에 UX 디자이너와 UI 디자이너를 구분하지 않고, UX/UI 디자이너로 통합해서 부르는 회사들도 많습니다.

좋은 사용자 경험을 위한 원칙

UX/UI 디자인 프로세스 단계
UX/UI 디자이너는 일반적으로 다음의 프로세스 단계를 따릅니다.

1. 아이디어 구현 및 정의
가장 먼저 우리가 제공하는 제품 또는 서비스에 대해 명확히 이해하는 것이 필요합니다. 이 단계에서는 마케터, 개발자 등 여러 이해관계자들과의 논의를 통해 비즈니스 목표를 식별하고 이를 달성하기 위해 어떤 전략이 필요할지 등을 정의합니다.

2. 연구조사
UX/UI 디자인의 핵심은 더 나은 사용자의 경험을 제공하는 것입니다. 이 단계에서는 사용자의 행동, 요구사항, 선호도 등을 이해하기 위해 사용자 대상의 인터뷰, 설문 조사 등을 실시합니다. 또한 시장조사를 통해 경쟁사와 시장의 동향을 파악하는 것도 도움이 됩니다.

3. 분석
앞서 수집한 정보를 토대로, 현재 제품 또는 서비스가 가진 문제점을 분석합니다. 이때 사용자 여정 지도(User Journey Map)을 활용하면 사용자 경험을 시각화해서 볼 수 있어, 문제를 파악하고 개선안을 도출하는 데 많은 도움을 줍니다.

4. 디자인
도출한 아이디어를 기반으로 와이어 프레임(Wireframe)과 프로토타입(Prototype)을 제작하여 디자인을 시각적으로 구체화합니다.

5. 테스트
제작한 디자인을 여러 사용자에게 테스트하고, 피드백을 수집하여 디자인의 문제점을 파악합니다.

6. 완료, 실행, 반복
테스트 결과를 바탕으로 제품을 수정하고 개선합니다. 사용자 피드백과 요구사항을 반영하여 디자인을 조정하고, 추가적인 테스트를 수행합니다. 이러한 과정을 반복하여 제품 또는 서비스를 지속적으로 발전시킵니다.

UX/UI 디자인 사례
마지막으로 UX/UI 디자인 사례 몇 가지를 살펴보고, 좋은 사용자 경험을 제공하는 디자인이란 무엇인지 함께 알아보도록 하겠습니다.

1. 에어비앤비(Airbnb)
에어비앤비는 여행지의 숙소를 예약할 때, 무척 간편한 웹사이트 이용 경험을 제공합니다.

홈페이지 디자인은 숙박을 찾는 여행객들이 일반적으로 겪는 문제들을 해결해 주는 데 초점이 맞춰져 있는데요. 화면 상단의 검색 필터를 사용하면 숙소의 유형, 가격대, 반려동물 동반 가능 여부, 주차시설 등 원하는 목록만 빠르게 탐색할 수 있도록 합니다.

어디로든 떠나고 싶은데 어디로 가야 할지 막막한 사람들에게는 숙소의 독특한 스타일, 근처의 즐길 거리를 기준으로 인기 숙소 리스트를 제안하여 여행 아이디어를 찾는 데도 도움을 줍니다.

2. 미로(Miro)
미로는 다수의 사람들이 디지털 화이트보드에 모여 브레인스토밍, 기획, 디자인 등 다양한 협업이 이루어질 수 있도록 도와주는 온라인 기반의 협업 플랫폼입니다. 미로의 특징 중 하나는 사용자가 서비스를 이용하는 과정에서 자연스럽게 ‘아하 모멘트’를 발견하도록 하는 것입니다.

아하 모멘트(Aha-Moment)란 사용자가 제품의 가치를 느끼는 첫 순간을 의미합니다. 무언가를 구매했을 때 “이거 꽤 괜찮네”, “잘 산 것 같아”라며 “아하!”하고 깨닫는 순간이죠. 사용자는 이런 경험을 통해 제품의 지속적인 사용을 결심하기 때문에 아하 모멘트를 이끌어내는 것은 매우 중요합니다.

미로는 사용자가 보드를 구축하는 과정에서 팝업을 통해 스스로 사용 방법을 학습할 수 있도록 지원합니다. 이때 팝업은 사용자의 행동에 맞춘 개인화된 가이드로 제공되며 단순 텍스트뿐만 아니라 영상, GIF 형태로도 제공되어 이해를 돕습니다. 또한, 화면 중앙이 아닌 사이드 영역에 노출되어 작업에 방해되지 않는 방식으로 제공됩니다. 이를 통해 사용자가 서비스에 쉽게 적응하고 아하 모먼트에 도달할 수 있도록 합니다.

3. 듀오링고(Duolingo)
듀오링고는 학습에 게임적인 요소(애니메이션, 레벨, 포인트 제도, 유저 랭킹 등)를 가미하여 언어 학습의 지루함을 덜어냈습니다. 이러한 요소들은 새로운 언어 학습을 재미있고 친근하게 만들어, 학습을 계속하도록 동기를 부여해 주는 역할을 합니다.


UX/UI 디자인은 사용자 경험과 가깝게 맞닿아 있는 만큼 프로덕트 성공에 매우 중요한 역할을 합니다. 우수한 사용자 경험은 제품이나 서비스의 가치를 향상시키는 데 큰 도움이 되는 반면, 사용자 요구와 목표를 충족시키지 못한다면 만족도와 경쟁력이 떨어질 수밖에 없기 때문입니다.

이는 IT 분야에서 UX/UI를 아는 PM이 주목받는 이유이기도 한데요. 프로덕트의 성공을 견인할 PM 커리어의 시작을 계획하고 있다면, 코드스테이츠 PM 부트캠프 함께 도전해 보세요.
