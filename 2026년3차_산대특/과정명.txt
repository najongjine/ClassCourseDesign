1. (산대특) 금속가공 부품 불량검사 AI 서비스 개발_지원

본 과정은 제조업 현장에서 발생하는 부품 외관 불량, 치수 불량, 표면 결함 등의 검사 업무에 AI를 활용할 수 있는 실무 역량을 기르는 것을 목표로 한다.

훈련생은 제조부품 이미지 데이터와 품질검사 데이터를 수집·정리하고, Python 기반 데이터 전처리, 이미지 분류 모델 학습, 불량 여부 예측, 검사 결과 해석, FastAPI 기반 AI 예측 API 구현, React 기반 검사 결과 화면 구현 과정을 학습한다.

최종적으로 훈련생은 부품 이미지 또는 검사 데이터를 입력하면 정상/불량 여부를 판정하고, 불량 가능성, 판정 결과, 검사 이력을 웹 화면으로 확인할 수 있는 AI활용 불량검사 서비스를 구현한다.

2. (산대특) 특수목적기계 생산관리 AI 예측·보고 자동화 실무_지원

본 과정은 특수 목적용 기계 제조업의 생산관리 업무에서 발생하는 자재입고, 재고, 생산실적, 납기 데이터를 활용하여 생산량과 자재 부족 위험을 예측하고, AI를 활용해 생산관리 보고서를 자동 작성할 수 있는 실무 역량을 기르는 것을 목표로 한다.

훈련생은 자재입고량, 자재사용량, 현재 재고, 생산계획량, 실제 생산량, 납기일 등의 데이터를 수집·정리하고, Python과 Pandas를 활용하여 생산현황과 재고 흐름을 분석한다. 이후 머신러닝 기반 예측 모델을 적용하여 생산량 예측, 자재 부족 위험 판단, 납기 지연 가능성 분석을 수행한다.

또한 분석 및 예측 결과를 FastAPI 기반 API와 React 기반 화면으로 구현하고, 생성형 AI를 활용하여 주간 생산현황 보고서, 자재 부족 위험 보고서, 납기 지연 예측 보고서 초안을 자동 작성하는 AI활용 생산관리 서비스를 개발한다.
