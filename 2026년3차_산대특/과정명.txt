1. (산대특) 금속가공 부품 불량검사 AI 서비스 개발_지원

본 과정은 제조업 현장에서 발생하는 부품 외관 불량, 치수 불량, 표면 결함 등의 검사 업무에 AI를 활용할 수 있는 실무 역량을 기르는 것을 목표로 한다.

훈련생은 제조부품 이미지 데이터와 품질검사 데이터를 수집·정리하고, Python 기반 데이터 전처리, 이미지 분류 모델 학습, 불량 여부 예측, 검사 결과 해석, FastAPI 기반 AI 예측 API 구현, React 기반 검사 결과 화면 구현 과정을 학습한다.

최종적으로 훈련생은 부품 이미지 또는 검사 데이터를 입력하면 정상/불량 여부를 판정하고, 불량 가능성, 판정 결과, 검사 이력을 웹 화면으로 확인할 수 있는 AI활용 불량검사 서비스를 구현한다.

2. (산대특) 플라스틱제품 생산관리 AI 예측·보고 자동화 실무_지원

본 과정은 플라스틱제품 제조업의 생산관리 업무에서 발생하는 주문량, 출고실적, 원재료 입고, 재고, 생산량, 불량수량, 납기 데이터를 활용하여 향후 제품 수요를 예측하고, 이에 따른 생산계획 수립과 자재 부족 위험 판단, 납기 지연 가능성 분석을 수행할 수 있는 AI활용 실무 역량을 기르는 것을 목표로 한다.

훈련생은 플라스틱 제품의 과거 주문량, 출고량, 생산실적, 원재료 입고량, 원재료 사용량, 현재 재고, 생산계획량, 실제 생산량, 불량수량, 납기일 등의 데이터를 수집·정리하고, Python과 Pandas를 활용하여 수요 변화, 생산현황, 재고 흐름, 계획 대비 실적 차이를 분석한다.

이후 머신러닝 기반 예측 모델을 적용하여 제품별 수요 예측, 생산량 예측, 원재료 소요량 예측, 원재료 부족 위험 판단, 납기 지연 가능성 분석을 수행한다. 또한 분석 및 예측 결과를 FastAPI 기반 API와 React 기반 화면으로 구현하고, 생성형 AI를 활용하여 주간 생산계획 보고서, 원재료 부족 위험 보고서, 납기 지연 예측 보고서 초안을 자동 작성하는 AI활용 생산관리 서비스를 개발한다.

3. 플라스틱 사출공정 원자재 자동 보급을 위한 ROS2 기반 자율주행 로봇 시뮬레이션 및 AI 재고 관제 서비스 개발

산업 현장

플라스틱 사출 제조업
예: 플라스틱 용기, 자동차 내장재, 전자제품 케이스, 생활용품 부품

현장 문제

플라스틱 사출공정에서는 사출기에 원자재 펠릿을 지속적으로 공급해야 한다. 원자재 투입이 늦어지면 생산이 중단되고, 너무 늦게 보급하면 작업자가 급하게 이동해야 한다.

명확한 목표

사출기별 원자재 잔량이 20% 이하로 떨어지면, 자율주행 로봇이 원자재 보관 구역에서 해당 사출기까지 원자재를 자동 운반하는 시뮬레이션 서비스를 개발한다.
